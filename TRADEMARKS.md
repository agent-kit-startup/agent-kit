# Names and logo

"Mission Kit", "Agent Kit" and the helmet logo name this project. The Apache License 2.0 covers the code, not the names or the logo (section 6).

- You may use the names to refer to the project, for example "works with Agent Kit" or "a fork of Mission Kit".
- If you publish a modified version, give it another name and logo, so nobody mistakes it for this project.
- Unmodified copies may keep the names and the logo.

Questions: open an issue in this repository.
