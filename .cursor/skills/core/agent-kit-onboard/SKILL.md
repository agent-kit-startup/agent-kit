# /agent-kit-onboard

Progressive repository readiness resolution, one essential check at a time, followed by an optional domain-skills scaffold.

## When to use

- Setting up a new project with Agent Kit for the first time
- Verifying repository readiness before starting plan work
- Resolving missing or incomplete Git, provider, branch strategy, or quality configuration
- Scaffolding project-owned domain skills after repository preparation

Do **not** use this for plan audits, inbox filing, or post-install overlay updates.
